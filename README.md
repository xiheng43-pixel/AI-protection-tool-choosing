# AI-protection-tool-choosing

##choosing.py
The first script, choosing.py, helps users select the most suitable security tool by answering 5 simple questions. It then provides a personalized recommendation from a predefined list of protection tools.

##parameter-calc.py
If no ideal match is found, or if you want to expand your list of alternative security tools, you can use the second script, parameter-calc.py, to calculate and evaluate various performance parameters of your security tool.

Note: The security tool used in this project is Promptfoo, so users may adjust the code format as needed. To run the script correctly, the security tool’s .yaml configuration file must be placed in the same folder as the code. If your security tool uses a format other than .yaml, you may modify the code accordingly.

##report.py
The third script, report.py, generates a clean, intuitive web-based report based on your security tool’s evaluation results. This report helps users better compare and choose the right protection tool.
